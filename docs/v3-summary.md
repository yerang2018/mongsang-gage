# 몽상가게 — 현재 최종 정리 (2026-11-05)

> 다른 AI(ChatGPT 등)와 이어서 기획할 때 붙여 넣는 용도의 요약입니다. 코드·비밀 키는 없습니다.

## 1. 한 줄 소개
좋은 꿈을 꾼 사람이 그 꿈을 **"꿈 구슬"**에 팔고, 중요한 날(면접·시험·발표·수능)을 앞둔 사람이 그 꿈의 좋은 기운을 사 가는 **모바일 웹 꿈 장터**.
"재미로 주고받는 꿈의 기운"이 콘셉트이며, 단정적인 운세·로또·복권 표현은 쓰지 않는다.

- 주소: https://mongsang-gage.vercel.app (운영), 시험판은 별도 미리보기 주소
- 기술: Next.js 15 + Supabase(DB·로그인) + Gemini(AI 해몽) + Unsplash(썸네일 사진) + Vercel(서버)
- 목표 일정: 11/9 완성 → 11/10~18 홍보 → 11/19 수능 아침에 "예약 열기" 선물이 열림
- 대상: 수능 수험생만이 아니라 **중요한 날을 앞둔 모든 사람**

## 2. 사용 흐름
1. **시작**: 닉네임만 적고 바로 시작(익명 로그인). 나중에 이메일을 연결하면 계정을 지킬 수 있고 보너스 구슬.
2. **꿈 올리기**: 어젯밤 꿈을 글로 적음 → AI가 해몽(상징 풀이·장면 풀이·점수 이유·행운이 오는 때·오늘의 조언)과 점수를 매김 → 봉투를 여는 연출로 등급 공개.
3. **팔기**: 결과 화면에서 [이 꿈 팔기] → 판매 서약 체크 → 공개 장터에 올라감. 꿈값은 등급으로 자동으로 정해짐(판 사람이 못 바꿈).
4. **사기**: 장터(당근마켓 같은 목록)에서 꿈을 고름 → 구슬로 삼 → 매매 증서(PNG) + 상세 해몽 열림.
5. **선물(행운 세트)**: 산 꿈을 친구에게 선물 링크로 보냄(로그인 없이 열림). 열리는 시각을 정할 수 있음(바로 / 수능날 아침 07:00 / 날짜 지정). 부적 그림(1080×1920) 포함. 나에게 부적으로 보내기도 가능.
6. **꿈 구해요**: "#합격운 꿈 구해요" 글을 올리면 다른 사람이 자기 꿈을 내밂 → 요청자가 하나 골라 삼. 글은 3일 열림.

## 3. 등급과 꿈값
점수 = 상징(5~65) + 기분(-5~12) + 행동(-5~13) + 생생함(0~10)

| 등급 | 점수 | 희귀도 | 꿈값 |
|---|---|---|---|
| 천운몽 | 90 이상 | 상위 5% | 500구슬 |
| 대길몽 | 78 이상 | 상위 17% | 300구슬 |
| 길몽 | 60 이상 | 상위 40% | 200구슬 |
| 소길몽 | 50 이상 | 상위 65% | 100구슬 |
| 평몽 | 20 이상 | — | 30구슬 |
| 액땜몽 | 20 미만 | — | 팔 수 없음 |

상징 순서: 용·봉황 > 돼지·조상 > 맑은 물 > 꽃·합격 > 일상 > 이빨·추락.

## 4. 돈 구조 (수익 구조)
- **꿈은 언제나 구슬로만 산다.** 구슬이 모자라면 돈으로 충전한다.
- **충전**: 1,000원 = 70구슬 / 3,000원 = 210구슬 / 5,000원 = 350구슬
  - 원래 1,000원 = 100구슬로 치고, **몽상가게 몫 30%를 충전할 때 미리 뗀다.**
- **꿈 거래 수수료 0**: 판 사람은 꿈값을 그대로 구슬로 받는다.
  - 예) 소길몽 100구슬을 사는 사람이 실제로 낸 돈은 약 1,430원
- **구슬 → 현금 출금은 없다.** 그래서 지금은 들어온 충전 금액 전부가 사실상 몽상가게 수입.
- **충전 방법(사업자 등록 전 임시)**: 충전 주문 → 4자리 주문번호 받음 → 카카오페이 송금 링크로 송금(메모에 주문번호, 금액은 직접 입력) → 운영자가 관리자 화면에서 [입금 확인] → 구슬 지급.
  - 쓰지 않은 충전 구슬은 환불(운영자가 직접 송금 반환).
- **무료 구슬(손님 끌기)**: 가입 50, 이메일 연결 +70, 꿈 기록 10(하루 3번). 매일 첫 방문 구슬은 없앰.
- **비용**: 지금은 서버·DB·AI·사진 모두 무료 등급이라 거의 0원. 꿈 1편당 AI 비용도 무료 등급이라 0원.
  - 주의: Vercel 무료 등급(Hobby)은 상업적 사용 금지 규칙이 있어 매출이 생기면 유료(Pro)로 바꾸는 게 안전.

## 5. 지금 고민 중인 문제 (열린 질문)
1. **파는 사람의 동기가 약하다**: 구슬을 돈으로 못 바꾸니 "왜 팔아야 하지?"가 약함.
   - 지금 파는 사람이 얻는 것: 받은 구슬로 다른 꿈 사기, "내 꿈이 팔렸다"는 재미
   - 아이디어(아직 안 만듦): ① 꿈이 팔리면 "면접 앞둔 누군가가 당신의 꿈을 가져갔어요" 알림 ② MY 화면에 판매 기록·뱃지 ③ 판 구슬로 친구에게 행운 세트 선물하기 연결
   - 테스트에서 "꿈을 기록한 사람 중 판매에 올리는 비율"을 재서 판단할 예정
2. **출금 / 실제 돈 거래로 바꿀까?**
   - A. 두 사람이 직접 송금(당근 직거래식): 몽상가게가 돈을 안 만져서 수수료를 받기 어려움. 소액이라 번거롭고 "돈 받았어요" 확인 다툼 가능
   - B. 몽상가게가 중간에서 받고 수수료 떼고 정산: 사실상 "충전 + 출금 열기"와 같은 구조. 사업자 등록, 전자금융 관련 법(결제 대행), 판매자 소득 세금, 결제 회사가 무형 상품을 거절할 가능성 등이 걸림
   - 지금 결론: **수능 테스트까지는 현재 구조 유지**, 판매 비율이 낮으면 사업자 등록 후 **충전으로 산 구슬만** 출금 열기 검토(무료 구슬까지 출금되면 계정 여러 개로 빼 가는 문제). 출금 시 수수료 30%를 10~20%로 낮출지도 검토
3. **"돈으로 바꿀 수 없다" 안내가 거의 안 보인다**: 지금은 MY 화면 꿈 구슬 옆 ⓘ 말풍선 안에만 있음. 꿈 파는 버튼 아래에 "팔린 꿈값은 구슬로 들어와요. 다른 꿈을 사거나 선물할 때 써요." 한 줄을 넣을지 결정 대기
4. **처음 가입 구슬 50개 vs 100개**: 100개면 가입하자마자 소길몽 하나를 살 수 있음. 결정 대기

## 6. 화면·디자인 원칙
- 당근마켓 같은 흰 바탕 + 보라 포인트, 아래 탭 두 개(MY · 장터)
- 장터 목록은 배달 앱 가게 목록처럼: 실제 사진 썸네일(Unsplash) + 제목 + 등급 딱지 + 점수·운 태그 + 시간·판 사람·꿈값
- 공개되는 닉네임은 첫 글자만(예*님), 가짜 활동은 만들지 않음(실제 거래만)
- 글꼴은 고운돋움 하나. 안내 문구는 최소로, 자세한 건 ⓘ 말풍선
- 해몽에 실제 사람·연예인·학교·회사 이름은 쓰지 않음("친구", "엄마"로 바꿈)
- 힘든 꿈은 저장하지 않고 위로의 말만 보여 줌
